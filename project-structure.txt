| Component     | Tech                       |
| ------------- | -------------------------- |
| Database      | MySQL (XAMPP)              |
| Backend API   | Next.js API routes         |
| Frontend UI   | Next.js (React/TSX)        |

i.e Lecturer → Question Bank → Paper Creation → Internal Review → Submit to HOD

HOD Receives Paper → Quality Review → Provide Feedback → 
    ↓
[APPROVE] → Forward to Exam Department
    ↓
[REJECT] → Return to Lecturer with Comments → Lecturer Revises → Resubmit

WORKFLOW:
1. Lecturer creates paper (draft)
2. Lecturer submits paper → status: 'submitted'
3. HOD reviews → status: 'hod_review'
4. HOD approves → status: 'hod_approved' → status: 'ready_for_print'
5. Exam Master prints → status: 'printing' → 'printed'
6. Paper published → status: 'published'
